# Contributing to TouchWorkstation Alpha

The most valuable contribution right now is **real-world testing**.

## Before opening a bug

Check existing issues first. If your problem already exists, add your environment and reproduction details there instead of opening a duplicate.

## Good bug reports include

- TouchWorkstation version
- Ubuntu version
- Device and browser
- What you were trying to do
- Exact steps that reproduce it
- Expected behavior
- Actual behavior
- Relevant screenshots/logs

## What to test

The highest-priority paths are:

1. Install / upgrade
2. Login / reconnect
3. Persistent terminal
4. Terminal mobile scrolling
5. Projects
6. Development previews
7. GitHub
8. Docker
9. Claude Code / Codex agent sessions
10. Agent Chat

## Feature requests

Feature ideas are welcome, but reliability bugs currently take priority over new capabilities.
